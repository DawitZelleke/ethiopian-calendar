# Map Mode

Narrated, subtitled, scored map videos made entirely by code. An episode is one story file; the engine
draws the satellite map, flies the camera, animates routes, kingdoms and labels, and times everything to
the narrator's words.

## Setup (once)

    ./setup.sh

Needs network access to raw.githubusercontent.com, gibs.earthdata.nasa.gov and
elevation-tiles-prod.s3.amazonaws.com, plus Node with Playwright and ffmpeg.

## Make an episode

    python3 narrate_ep.py day1                                   # voice + word timings (ElevenLabs)
    node score-times.js episodes/day1/ethio.js episodes/day1/timing.js episodes/day1/ethio.json
    python3 music_ethio.py episodes/day1/ethio.json episodes/day1/music.wav   # or music.py with score.js
    ./mix.sh episodes/day1/voice.wav episodes/day1/music.wav episodes/day1/mix.wav
    node render_ep.js day1 episodes/day1/day1.mp4 episodes/day1/mix.wav

Check frames without rendering: `node ep-stills.js day1 sheet.png L2+1 W5:water END-3`.

## Story files

`episodes/<id>/story.js` holds the captions (and optional Amharic `subtitles`), what the narrator says,
the camera path, and the layers (kingdoms, regions, routes, markers, pills, ripples, fire, arcs).
Times are written against the narration: `L2` (line 2 starts), `L2e` (ends), `W1:spices` (the moment
that word is spoken), `END`, with `+0.4` / `-0.4` offsets. Change the words and everything re-times.
